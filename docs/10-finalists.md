# Финалисты (Finalists)

API v3: `/api/v3/finalists`

Финалисты — кандидаты, прошедшие все этапы отбора и принятые на работу.

## Статусы финалиста

| state | Описание |
|-------|----------|
| `ready_to_send` | Готов к отправке данных во внешнюю HR-систему |
| `sent` | Данные успешно отправлены |
| `sent_with_error` | Ошибка при отправке |
| `sending_in_process` | Отправка в процессе |
| `cancel_hire` | Инициирована отмена найма |
| `hire_canceled` | Найм отменён |

---

### GET /api/v3/finalists

**Когда использовать:** Получить список принятых кандидатов. Используйте для отчётов по найму, синхронизации с HR-системами, аналитики.

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `job_id` | integer | Нет | Фильтр по вакансии |
| `state` | string | Нет | Фильтр по статусу |
| `page_size` | integer | Нет | Записей на странице (1-100, по умолчанию 20) |
| `page_cursor` | string | Нет | Курсор |

**Ответ 200:**
```json
{
  "objects": [
    {"id": 123, "applicant_id": 456, "job_id": 789, "state": "sent", "created_at": "2024-01-15T10:30:00Z"}
  ],
  "has_next_page": true,
  "page_next_cursor": "eyJpZCI6MTI0fQ=="
}
```

---

### GET /api/v3/finalists/:id

**Когда использовать:** Получить данные конкретного финалиста.

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `id` | integer | Да | ID финалиста (path) |

---

### POST /api/v3/finalists/:id/change_state

**Когда использовать:** Сменить статус финалиста (например, отменить найм).

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `id` | integer | Да | ID финалиста (path) |
| `state` | string | Да | Новый статус |
