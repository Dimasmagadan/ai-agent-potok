# Open API — Карьерный сайт

Base URL: `https://{subdomain}.potok.io/open/`

Публичный API для карьерных сайтов. **Не требует аутентификации.** Работает на основе поддомена компании.

> Для работы должен быть включён флаг `potok_career_site_enabled` в настройках компании.

---

### GET /open/jobs

**Когда использовать:** Получить список опубликованных вакансий компании для карьерного сайта или чат-бота.

Параметры: нет

**Ответ:** HTML-страница со списком вакансий, сгруппированных по отделам.

**Условия отображения:** вакансия активна + опубликована на карьерном сайте.

> Для JSON-ответа используйте конструктор (GET /open/constructor/:id).

---

### GET /open/jobs/:id

**Когда использовать:** Получить детали вакансии (описание, город, зарплата).

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `id` | integer | Да | ID вакансии (path) |

**Ответ:** HTML-страница с описанием вакансии и кнопкой «Откликнуться».

**Редиректы:**
- 302 → `/open/jobs/:id/closed` — вакансия снята с публикации
- 404 — вакансия не найдена

**Google Jobs:** Если включено — автоматически добавляет JSON-LD разметку Schema.org (JobPosting) для индексации Google.

---

### GET /open/jobs/:id/apply

**Когда использовать:** Показать форму отклика на вакансию.

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `id` | integer | Да | ID вакансии (path) |

**Ответ:** HTML-форма с полями для имени, контактов и загрузки резюме.

---

### POST /open/jobs/:id/apply

**Когда использовать:** Отправить отклик на вакансию. Создаёт кандидата и добавляет на вакансию.

**Content-Type:** `multipart/form-data`

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `id` | integer | Да | ID вакансии (path) |
| `first_name` | string | Да | Имя |
| `last_name` | string | Да | Фамилия |
| `phone` | string | Нет | Телефон |
| `email` | string | Нет | Email |
| `resume` | file | Нет | Файл резюме |

**Ответ:** 302 редирект на страницу успешного отклика.

**Трекинг:** Автоматически сохраняет UTM-метки и referer.

---

### GET /open/constructor/:id

**Когда использовать:** Получить JSON-данные конструктора карьерного сайта (структурированные данные о вакансиях для iframe-виджета).

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `id` | integer | Да | ID конструктора (path) |

**Ответ:** JSON с данными для построения карьерной страницы.
