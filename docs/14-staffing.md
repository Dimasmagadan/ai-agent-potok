# Штатное расписание и заявки (Staffing & Demands)

API v3: `/api/v3/demands`, `/api/v3/business_units`, `/api/v3/staffing_items`, `/api/v3/sprints`

Модуль кадрового планирования: организационная структура, штатное расписание, заявки на подбор и спринты планирования.

> Эти эндпоинты доступны только если у компании подключён модуль штатного расписания.

---

## Заявки на подбор (Demands)

### GET /api/v3/demands

**Когда использовать:** Получить заявки на подбор персонала. Заявка — это запрос от бизнеса на закрытие позиции: сколько человек нужно, к какому сроку, на какую должность.

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `page` | integer | Нет | Номер страницы (с 1) |
| `per_page` | integer | Нет | Записей на странице (по умолчанию 20, макс 100) |
| `f[statuses][]` | array | Нет | Фильтр по статусу: `initialized`, `approved`, `archived` |

**Ответ 200:**
```json
{
  "page": 1,
  "per_page": 20,
  "total_pages": 10,
  "objects": [{
    "id": 2758,
    "quantity": 2,
    "job_id": 228729,
    "business_unit_id": 2952,
    "comment": "Нужен срочно к старту проекта",
    "start_date": "2024-02-01",
    "finish_date": "2024-03-15",
    "staffing_item_full_ext_id": "position_1022658",
    "states": [{"state_id": "approved", "updated_at": "2024-01-20T10:00:00Z"}],
    "sprint": {"id": 5, "name": "01.02 - 28.02", "start_date": "2024-02-01", "finish_date": "2024-02-28"},
    "author": {"id": 501, "name": "Иванова Мария", "email": "ivanova@company.com"},
    "executive": {"id": 502, "name": "Петров Иван", "email": "petrov@company.com"},
    "priority_item": {"id": 1, "name": "Высокий", "color_hex": "#FF0000"}
  }]
}
```

**Ключевые поля:**
- `quantity` — сколько человек нужно нанять
- `job_id` — связанная вакансия (может быть null, если вакансия ещё не создана)
- `states` — текущий статус заявки (initialized → approved → archived)
- `sprint` — спринт планирования, к которому относится заявка
- `executive` — ответственный рекрутер
- `priority_item` — приоритет заявки

### GET /api/v3/demands/:id

**Когда использовать:** Получить детали конкретной заявки по ID.

## Организационная структура

### GET /api/v3/business_units

**Когда использовать:** Получить список бизнес-юнитов (подразделений) компании. Бизнес-юниты используются для группировки заявок и вакансий по организационной структуре.

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `page` | integer | Нет | Номер страницы |
| `per_page` | integer | Нет | Записей на странице (по умолчанию 50) |

**Ответ 200:**
```json
{
  "page": 1,
  "per_page": 50,
  "total_pages": 3,
  "objects": [{
    "id": 2812,
    "name": "IT-департамент",
    "code": "it_department",
    "city": {"id": "1", "name": "Москва"}
  }]
}
```

### GET /api/v3/staffing_items/paged

**Когда использовать:** Получить штатное расписание — дерево подразделений и должностей. Курсорная пагинация.

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `page_size` | integer | Нет | Записей на странице (по умолчанию 20, макс 100) |
| `page_cursor` | string | Нет | Курсор |

**Ответ 200:**
```json
{
  "objects": [{
    "id": "department_515",
    "name": "Отдел разработки",
    "item_type": "department",
    "start_date": "2020-01-01",
    "end_date": null,
    "parent_id": null,
    "dynamic_fields": []
  }, {
    "id": "position_1022658",
    "name": "Senior Developer",
    "item_type": "position",
    "parent_id": "department_515"
  }],
  "has_next_page": true,
  "page_next_cursor": "eyJpZCI6MTAyMjY1OH0="
}
```

**Поле `item_type`:** `department` (подразделение), `position` (должность), `new_position` (новая должность)

**Поле `parent_id`:** ID родительского элемента — позволяет построить дерево оргструктуры

### GET /api/v3/sprints

**Когда использовать:** Получить текущие и будущие спринты планирования. Спринты задают временные рамки для заявок на подбор.

Параметры: нет

**Ответ 200:**
```json
{
  "objects": [
    {"id": 5, "name": "01.02 - 28.02", "start_date": "2024-02-01", "finish_date": "2024-02-28", "start_status": "current"},
    {"id": 6, "name": "01.03 - 31.03", "start_date": "2024-03-01", "finish_date": "2024-03-31", "start_status": "future"}
  ]
}
```

> Возвращает только актуальные спринты (finish_date >= сегодня). Максимум 2 спринта.
