# Поток API — документация для AI-агентов

Поток (potok.io) — рекрутинговая платформа для управления вакансиями, кандидатами и процессом найма. Эта документация создана специально для использования AI-агентами: компактная, структурированная, с описаниями «когда использовать» и пошаговыми сценариями.

## Как использовать

**Загрузить всё целиком** (~25K токенов без tools.json, ~36K с ним): подходит для моделей с большим контекстом. Загрузите все файлы в system prompt или в базу знаний агента.

**Загрузить выборочно**: начните с `00-quickstart.md` + `01-domain-model.md`, затем добавьте нужные домены.

**Типичные наборы:**

| Задача агента | Какие файлы загрузить |
|---------------|----------------------|
| Управление вакансиями и кандидатами | 00 + 01 + 02-jobs + 03-applicants + 04-ajs-joins |
| Аналитика рекрутинга | 00 + 01 + 02-jobs + 03-applicants + 05-events |
| Кадровое планирование | 00 + 01 + 02-jobs + 14-staffing |
| Карьерный сайт / чат-бот | 00 + 01 + 03-applicants + 11-career-api |
| Интеграция с внешней системой | 00 + 01 + 15-webhooks + 16-integration + 03 + 05 + 06 |
| Полный агент-рекрутер | Все файлы |

## Формат описания эндпоинтов

Каждый эндпоинт описан по шаблону:
- **Когда использовать** — intent-описание для агента
- **Связь** — какие сущности затрагивает
- **Параметры** — таблица с типами
- **Запрос/Ответ** — компактные JSON-примеры
- **Ошибки** — типичные ошибки inline
- **Следующий шаг** — что вызвать дальше

## tools.json

Файл `tools.json` содержит 39 определений инструментов в формате function calling. Каждый инструмент включает `name`, `description` (на русском, intent-first), `http` (method + path) и `parameters` (JSON Schema).

Подходит для автоматического создания инструментов в LangChain, CrewAI, AutoGPT и других фреймворках.

**Домены:** Jobs (9), Applicants (7), AJS Joins (7), Events (3), Documents (2), Calendar (2), Users (2), Dictionaries (5), Finalists (2)
