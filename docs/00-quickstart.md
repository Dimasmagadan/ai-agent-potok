# Быстрый старт

## Base URLs

- **API v3** (основной): `https://demo.app.potok.io/api/v3`
- **API v2** (события, документы): `https://demo.app.potok.io/api/v2`
- **Open API** (карьерный сайт): `https://demo.app.potok.io/open`

## Аутентификация

Все запросы требуют Bearer-токен в заголовке:

```
Authorization: Bearer YOUR_TOKEN
Content-Type: application/json
```

Токен генерируется в настройках компании → раздел «Генерация токенов».

Альтернатива для инструментов без поддержки заголовков — токен query-параметром: `GET /api/v3/applicants.json?token=<TOKEN>`. Предпочитайте заголовок: токен в URL оседает в логах.

## Rate Limits

- **100 запросов за 10 секунд** на один токен
- При превышении — ответ `429 Too Many Requests`
- Рекомендация: экспоненциальный backoff (1с → 2с → 4с), максимум 3 повтора

## Пагинация

Два формата в зависимости от эндпоинта:

**Страничная** (большинство эндпоинтов):
```
GET /api/v3/jobs?page=2&per_page=50
```
Ответ содержит: `page`, `pages` (всего страниц), `per_page`

**Курсорная** (events_stream):
```
GET /api/v2/events_stream?page_cursor=abc123&page_size=100
```
Ответ содержит: `page_next_cursor`, `has_next_page`

## Формат данных

- **Даты**: ISO 8601 — `2024-01-15T12:00:00.000+03:00`
- **Тело запроса**: JSON (`Content-Type: application/json`), кроме загрузки файлов (`multipart/form-data`)
- **Пустые значения**: `null` или отсутствуют в ответе
- **Массивы в GET-запросах**: формат `by_created_at[]=2024-01-01T00:00:00Z&by_created_at[]=2024-12-31T23:59:59Z`

## Коды ошибок

| Код | Значение | Что делать |
|-----|----------|------------|
| 400 | Неверные параметры запроса | Проверить формат параметров |
| 401 | Невалидный или просроченный токен | Проверить Authorization заголовок |
| 402 | Подписка просрочена | Связаться с администратором |
| 404 | Объект не найден | Проверить ID в запросе |
| 422 | Ошибка валидации | Ответ содержит `{"errors": {"field": ["message"]}}` |
| 429 | Превышен rate limit | Подождать и повторить с backoff |
| 500 | Внутренняя ошибка сервера | Повторить позже |

## Формат ошибок валидации (422)

```json
{"errors": {"name": ["не может быть пустым"], "email": ["уже существует"]}}
```

## Версии API

- **v3** — основная версия для вакансий, кандидатов, пользователей, воронки
- **v2** — события (комментарии, звонки), документы, справочники
- Оба API используют один токен и одну аутентификацию
