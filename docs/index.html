AI Agent Challenge 2026

Рекрутинг без лишних действий в ATS.

AI-агент для «Потока» помогает находить кандидатов, вакансии и карьерные возможности, не меняя данные в системе.

Открыть проект Запустить за 30 секунд

Задайте вопрос обычным языком

«Найди backend-разработчиков в резерве со знанием Python и FastAPI»
«Кого стоит пересмотреть после расширения вилки?»
«Какие вакансии мне подходят и чего не хватает для роли №9?»
Пять рабочих сценариев

От резерва до внутренней мобильности

01

Кадровый резерв

Понимает запрос в свободной форме, учитывает синонимы, ранжирует кандидатов и показывает подтверждающие цитаты.

02

Дедупликация

Находит карточки с одинаковыми нормализованными телефоном или адресом электронной почты, без догадок по ФИО.

03

Возврат кандидатов

Показывает, к кому вернуться после изменения вилки, графика, локации, опыта или профиля роли.

04

Подбор вакансий

Соискатель описывает опыт в свободной форме и получает подходящие открытые вакансии с ссылкой для отклика.

05

Внутренняя мобильность

Сотрудники видят подходящие роли, включая неопубликованные, и понимают, чего может не хватать для конкретной вакансии.

∞

Безопасно по умолчанию

Только чтение: никаких тегов, комментариев, перемещений по воронке или откликов от имени человека.

Быстрый старт

Проверьте проект без доступа к API

В репозитории есть обезличенные данные и локальная имитация API. Нужен только Python 3.

  1. Клонируйте репозиторийgit clone https://github.com/Dimasmagadan/ai-agent-potok.git
  2. Запустите тестыmake test запускает 136 автономных тестов без сети.
  3. Посмотрите демоmake demo последовательно показывает ключевые сценарии на локальном API.
