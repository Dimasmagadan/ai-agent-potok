# События (Events)

API v2: `/api/v2/events`

События — комментарии, звонки, встречи и другая активность, привязанная к кандидату и вакансии. Два эндпоинта для чтения: постраничный (events) и курсорный (events_stream).

---

### GET /api/v2/events

**Когда использовать:** Получить список событий с постраничной пагинацией. Подходит для просмотра последних событий, фильтрации по кандидату или периоду.

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `page` | integer | Нет | Номер страницы (с 1) |
| `per_page` | integer | Нет | Записей на странице (по умолчанию 50, макс 50) |
| `applicant_id` | integer | Нет | Фильтр по кандидату |
| `by_created_at[]` | datetime | Нет | Период: 2 даты (начало и конец) |

**Формат фильтра по дате:**
```
?by_created_at[]=2024-01-01T00:00:00Z&by_created_at[]=2024-01-31T23:59:59Z
```

**Ответ 200:**
```json
{
  "data": [{
    "id": 123456,
    "type": "Event::Comment",
    "body": "Отличный кандидат, рекомендую к собеседованию",
    "applicant_id": 12345,
    "job_id": 555,
    "author_id": 789,
    "private": false,
    "stage_type": "screening",
    "created_at": "2024-01-15T10:30:00.000Z"
  }],
  "page": 1, "pages": 10, "per_page": 50
}
```

**Типы событий (поле `type`):**

| type | Описание |
|------|----------|
| `Event::Comment` | Комментарий |
| `Event::Call` | Звонок |
| `Event::Meeting` | Встреча |
| `Event::Email` | Письмо |
| `Event::Task` | Задача |
| `Event::StageChanged` | Смена этапа (системное) |
| `Event::StateChanged` | Смена статуса (системное) |

### GET /api/v2/events_stream

**Когда использовать:** Загрузить большой объём событий через курсорную пагинацию. Оптимизирован для синхронизации — позволяет забрать все события последовательно.

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `page_size` | integer | Нет | Записей на странице (по умолчанию 20) |
| `page_cursor` | string | Нет | Курсор для следующей страницы |
| `applicant_id` | integer | Нет | Фильтр по кандидату |
| `by_created_at[]` | datetime | Нет | Период (2 даты) |

**Алгоритм обхода:**
1. Первый запрос без `page_cursor`
2. Из ответа берём `page_next_cursor`
3. Следующий запрос с `page_cursor` = значение из п.2
4. Повторяем, пока `has_next_page` = false

**Ответ 200:**
```json
{
  "objects": [{
    "id": 123456,
    "type": "Event::Comment",
    "body": "Текст комментария",
    "applicant_id": 12345,
    "job_id": 555,
    "author_id": 789,
    "created_at": "2024-01-15T10:30:00.000Z"
  }],
  "page_next_cursor": "eyJpZCI6MTIzNDU1LC...",
  "has_next_page": true
}
```

**Сортировка:** от новых к старым (по `created_at` DESC)

### POST /api/v2/events

**Когда использовать:** Добавить комментарий или заметку к кандидату. Можно привязать к конкретной вакансии.

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `applicant_id` | integer | Да | ID кандидата |
| `body` | string | Да | Текст комментария |
| `type` | string | Нет | Тип: `comment` (по умолчанию), `call`, `meeting`, `email`, `task` |
| `job_id` | integer | Нет | ID вакансии (привязка к конкретной вакансии) |
| `private` | boolean | Нет | Приватный (видят только автор и админы) |
| `attach_document_ids` | array | Нет | ID документов для прикрепления (сначала создайте документ — Рецепт 12 в [13-recipes.md](13-recipes.md)) |

**Запрос:**
```json
{"applicant_id": 12345, "body": "Провёл телефонное интервью. Хороший кандидат.", "type": "comment", "job_id": 555}
```

**Ответ 200:**
```json
{
  "id": 789,
  "body": "Провёл телефонное интервью. Хороший кандидат.",
  "type": "comment",
  "applicant": {"id": 12345, "first_name": "Иван", "last_name": "Петров"},
  "job": {"id": 555, "name": "Программист"}
}
```
