# Пользователи (Users)

API v3: `/api/v3/users`

Пользователи — рекрутеры и менеджеры компании. Нужны для назначения ответственных за вакансии и кандидатов.

---

### GET /api/v3/users

**Когда использовать:** Получить список пользователей компании. Используйте для поиска рекрутеров перед назначением на вакансию.

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `page` | integer | Нет | Номер страницы (с 1) |
| `per_page` | integer | Нет | Записей на странице (по умолчанию 10, макс 100) |
| `f[emails][]` | array | Нет | Фильтр по email-адресам |

**Ответ 200:**
```json
{
  "objects": [
    {
      "id": 123,
      "name": "Иванов Иван",
      "email": "ivanov@company.com",
      "avatar": "https://storage.potok.io/avatars/123.jpg",
      "phones": ["+7 (999) 123-45-67"],
      "whatsapp": "+79991234567",
      "telegram": "@ivanov"
    }
  ],
  "page": 1, "per_page": 10, "total_pages": 3
}
```

---

### GET /api/v3/users/:id

**Когда использовать:** Получить данные конкретного пользователя по ID.

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `id` | integer | Да | ID пользователя (path) |

---

### POST /api/v3/users/substitutes

**Когда использовать:** Настроить замещение — перенаправить все вакансии и кандидатов с одного рекрутера на другого (отпуск, больничный).

| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| `user_id` | integer | Да | ID замещаемого пользователя |
| `substitute_user_id` | integer | Да | ID замещающего пользователя |

---

## Модель User

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer | ID пользователя |
| `name` | string | Полное имя |
| `email` | string | Email (уникальный в компании) |
| `avatar` | string/null | URL аватара |
| `phones` | array | Список телефонов |
| `whatsapp` | string/null | WhatsApp номер |
| `telegram` | string/null | Telegram username |
