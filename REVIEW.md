## Баги

### 1. HIGH — Дедуп пропускает телефоны с ведущей «8»

`scripts/talent_pool.py:92-93`: нормализация — просто удалить все нецифры. Тогда:

```
"+79161234503"      → 79161234503
"8 916 123 45 03"   → 89161234503   ≠  НЕ дубль
```

Это ровно тот формат, который сам SDD §1.2 закладывает в сид-данные живого тенанта (id37/id52, «формат `8 916 123 45 03` вместо `+7...`»). Российские номера с «8» — массовый кейс, часть реальных дублей будет молча теряться. Фикс — приводить к последним 10 цифрам:

```python
def _normalize_phone(phone):
    digits = re.sub(r"\D", "", phone or "")
    return digits[-10:] if len(digits) == 11 else digits
```

(Для международных номеров длиной >11 оставить как есть.)

### 2. MEDIUM — Подстрочный матчинг даёт ложные совпадения

`scripts/talent_pool.py:122`: `"term in haystack"`. Подтверждено: терм **«java» матчится с title «JavaScript developer»**. Аналогично «go» ⊂ «golang», «c++»/«c», короткие русские корни. На демо это может выдать нерелевантного кандидата с уверенным evidence. Минимальный фикс — матчить по границам слов:

```python
haystack_words = set(re.findall(r"\w+", haystack))
matched = [t for t in terms if t["term"].lower() in haystack_words]
```

(Тогда «c++» и «1C» потребуют аккуратности с `\w+` — протестировать на fixture-терминах.)

### 3. LOW — Нет таймаута у HTTP-запросов

`scripts/talent_pool.py:29`: `urlopen(req)` без `timeout=` — на флапающем интернете скрипт виснет бесконечно, а не падает с понятной ошибкой. Фикс: `urlopen(req, timeout=30)`.

### 4. LOW — Backoff на 429 игнорирует `Retry-After`

`scripts/talent_pool.py:31-34`: фиксированные паузы 1/2/4 c. Работает, но уважение к заголовку `Retry-After` было бы корректнее и быстрее. Приемлемо для MVP (SDD §8 риск зафиксирован).

### 5. NIT — Занятый порт у mock-сервера = голый traceback

`scripts/mock_server.py:64`: при повторном запуске — `OSError: [Errno 48]`. Обернуть в try/except с сообщением «порт занят — сервер уже запущен?» (ловится легко, я сам на этом споткнулся при проверке).
