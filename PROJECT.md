# Поток Agent Challenge

Проект для конкурса ИИ-агентов «Поток» — https://events.potok.io/ai_agent_hr_contest

## Условия конкурса

**Суть:** создать ИИ-агента на базе открытого API платформы «Поток» (potok.io) для решения реальной HR-задачи.

**Формат — любой:**
- Скилл для LLM
- Workflow в n8n
- Python-приложение
- Интеграция с другими сервисами
- Любое решение на основе открытого API

**Область применения (на выбор):** рекрутмент, онбординг, оценка сотрудников, карьерное развитие, обучение, наставничество, HR-аналитика, employee experience — или своя идея.

**Критерии оценки:**
1. **Полезность** — решает реальную HR-задачу с интеграцией «Потока»
2. **Воспроизводимость** — проект можно подключить и запустить без автора
3. **Оригинальность идеи** — нестандартные сценарии использования API

**Сроки:** приём заявок открыт до **6 сентября 2026**.

**Процесс участия:**
1. Получение доступа к API и песочнице
2. Разработка агента
3. Представление проекта
4. Экспертный отбор
5. Выступление на демодне
6. Попадание лучших в витрину ИИ-агентов Потока

**Требования:**
- Можно участвовать индивидуально или командой
- Обязательно использование открытого API «Потока»
- Разрешено использовать любые LLM и AI-инструменты
- Можно представить существующий проект

**Права и обязательства:** все права остаются у авторов, единственное условие — публикация проекта как open source.

**Призы/преимущества:** лучшие проекты получают место в витрине готовых решений «Потока» и доступны компаниям для реальных процессов.

## API «Поток» — что доступно

Документация: [`docs/`](docs/README.md). Рекрутинговая платформа: вакансии, кандидаты, воронка найма. 17 markdown-файлов + `docs/tools.json` (39 готовых function-calling инструментов, JSON Schema).

### Технические условия

- **Auth:** Bearer-токен в заголовке `Authorization`, генерируется в настройках компании
- **Base URLs:** v3 (вакансии/кандидаты/воронка/пользователи), v2 (события, документы, справочники), Open API (карьерный сайт, без токена)
- **Rate limit:** 100 запросов / 10 сек на токен, при превышении — 429
- **Формат:** JSON (кроме загрузки файлов — multipart/form-data), даты ISO 8601
- **Пагинация:** постраничная (`page`/`per_page`) для большинства, курсорная для `events_stream`

### Домены API

Центральная сущность — **AJS Join** (Applicant↔Job↔Stage): через неё всё управление воронкой.

| Домен | Что даёт |
|---|---|
| Jobs | CRUD вакансий, статусы, воронка, команда |
| Applicants | CRUD кандидатов, поиск, резюме |
| AJS Joins | перемещение кандидата по этапам воронки |
| Events | комментарии, звонки, активность, стрим событий |
| Documents | загрузка резюме/файлов |
| Calendar | интервью, напоминания |
| Dictionaries | справочники (города, причины отказа и т.д.) |
| Users | пользователи, отделы, роли |
| Finalists | принятые кандидаты |
| Career API | открытое API для карьерного сайта/чат-бота (без токена) |
| OAuth2 | для сторонних интеграций |
| Webhooks | пуш-события из Потока (настраиваются по запросу) |

Жизненный цикл кандидата: `создание → добавление на вакансию (AJS Join) → перемещение по этапам → принят (Finalist) / отклонён (decline + причина)`.

`docs/13-recipes.md` — 12 готовых пошаговых сценариев для типовых агентских флоу.
